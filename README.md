# muk-web-19 — MuK Web modules pour Odoo 19 (miroir Renoware)

Miroir des modules MuK Web 19.0.1.4.3 utilisés par les instances IBATIX.
Source : MuK Store (https://store.mukit.at/) — modules LGPL-3 redistribuables.

Pourquoi un miroir : muk-it/muk_web sur GitHub s'arrête à Odoo 16. Les
versions 17.0+ ne sont disponibles que sur le MuK Store. On miroir ici
pour pouvoir les déclarer dans `repos.yaml` de `ibatix-stack` et qu'ils
soient pullés automatiquement par doodba sur chaque client.

## Modules

- muk_web_appsbar
- muk_web_chatter
- muk_web_colors
- muk_web_dialog
- muk_web_group
- muk_web_refresh
- muk_web_theme
